# Awaaz-e-Pakistan: Your Digital Home Companion

Build a fully functional, production-ready, mobile-responsive web application prototype named “Awaaz-e-Pakistan” for Pakistani households. Implement the detailed three-tab experience exactly as requested: Utility Bill Audit & Appliance Coach, Leftover Recipe Maker, and Local Market Grocery Value Finder. Use a modern clean civic/Pakistani visual style, persistent branded header with flag accent, Tailwind CSS and Lucide icons, responsive bottom navigation on mobile and appropriate desktop navigation. All inputs need realistic defaults/dummy data and buttons must produce rich, error-free interactive outputs, with smooth tab transitions.
